# Hotel Management API

A Hotel Management REST API developed using Spring Boot to manage hotel information and user operations.

## Features

- User registration and login
- JWT-based authentication
- Role-based authorization
- Hotel CRUD operations
- Secure REST APIs

## Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman
